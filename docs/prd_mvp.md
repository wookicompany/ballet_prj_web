Product Requirement Document (MVP)

1. 제품 개요
   서비스명: 마이발레

정의: 개인의 발레 활동을 캘린더 기반으로 기록·관리하는 모바일 앱
포지션: 개인 기록 중심 서비스

---

2. 목표

- 발레 기록을 빠르고 직관적으로 남길 수 있는 경험 제공
- 하루 여러 건의 기록을 시간 단위로 관리
- 로그인부터 기록 생성·조회·수정·삭제까지 완결된 개인 사용자 플로우 제공

---

3. 대상 사용자

- 취미 발레 수강자
- 전공 및 입시 준비생
- 개인 발레 히스토리를 체계적으로 관리하고 싶은 사용자

---

4. 화면 구성

1) 로그인 화면
2) 캘린더 화면 (메인)
- 플로팅 버튼: 발레 기록 생성 화면으로 이동
3) 일별 상세 화면 (타임라인)
- 플로팅 버튼: 발레 기록 생성 화면으로 이동
4) 발레 기록 생성 화면
5) 발레 기록 상세(읽기) 화면
6) 발레 기록 수정 화면
7) 프로필 화면
8) 프로필 설정 화면

---

5. 핵심 사용자 플로우

1) 앱 실행
2) 로그인 (카카오 / 구글)
3) 캘린더 화면 진입
4) 사용자 행동 선택
- 날짜 선택 → 일별 상세 화면 진입
- 플로팅 버튼 선택 → 발레 기록 생성 화면 이동
5) 일별 상세 화면
- 00:00 ~ 24:00 기준 세로 스크롤 타임라인
- 기록 블록 선택 → 기록 상세 화면 이동
- 플로팅 버튼 선택 → 발레 기록 생성 화면 이동
6) 기록 저장
7) 캘린더 및 일별 상세 화면에 기록 반영
8) 프로필 확인 및 설정

---

6. 기능 요구사항

1) 로그인

- 카카오 소셜 로그인
- 구글 소셜 로그인
- 로그인 상태 유지

2. 캘린더

- 월간 캘린더 뷰
- 날짜별 발레 기록 존재 여부 표시
- 날짜 선택 시 일별 상세 화면으로 이동

3. 일별 상세 화면 (타임라인)

- 선택한 날짜 기준 단일 화면
- 00:00 ~ 24:00 세로 스크롤 구조
- 시간대별 구획이 명확히 보이는 UI
- 발레 기록을 시간 블록 형태로 배치
- 빈 시간대 선택 시 발레 기록 생성 가능

4. 발레 기록

- 기록 단위: 날짜 + 시작 시간 ~ 종료 시간
- 하루 여러 건 기록 가능

입력 항목

- 날짜 (자동 기입)
- 시작 시간
- 종료 시간
- 기록 내용
- 미디어
    - 사진 최대 3장
    - 영상 최대 1개
- 감정 상태 (별점 또는 체크 방식 UI)
- 장소
- 레벨
- 강사
- 오늘 수업 어땠는지?
- 바(bar) 순서
- 센터(center) 순서
- 오늘 새롭게 배운 것
- 수업에서 받은 피드백
- 오늘 잘한 것
- 다음에 더 신경 써야 하는 것

기능

- 생성(Create)
- 조회(Read)
- 수정(Update)
- 삭제(Delete)

5. 프로필

- 프로필 이미지
- 닉네임
- 가입일
- 누적 정보
  - 나의 총 발레 시간
  - 기록 개수
6. 프로필 설정

- 프로필 이미지 변경
- 닉네임 변경
- 로그아웃

---

7. 비기능 요구사항

- 모바일 퍼스트 UI
